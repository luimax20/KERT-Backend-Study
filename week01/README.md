# KERT 웹 백엔드 스터디 - 1주차

## 실행 방법
1. 프로젝트 폴더로 이동: `cd week01`
2. 패키지 설치: `npm install`
3. 서버 실행: `npm run dev`

## 구현한 라우트
- `/`: 메인 페이지 ("Hello Express!")
- `/about`: 자기소개 페이지
- `/photo`: 동아리 사진 출력 페이지 (`KERT.jpg`)
- `/time`: 접속 시각 출력 페이지
- `/posts`: 게시글 목록 HTML 출력 페이지
- `404 Handler`: 존재하지 않는 경로 접속 처리

## (도전) /time 이 새로고침할 때마다 바뀌는 이유
브라우저에서 새로고침을 할 때마다 클라이언트가 서버로 새로운 HTTP GET 요청을 보냅니다.
이때 Express 서버의 `/time` 라우트 핸들러 함수가 새로 실행되면서 `new Date()`를 매번 새롭게 호출해 현재 시각을 구한 뒤 응답으로 보내주기 때문입니다.
