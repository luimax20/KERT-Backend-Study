# KERT 웹 백엔드 스터디 - 3주차 (DB 연동 및 인증/권한)

## 실행 방법
1. 프로젝트 폴더로 이동: `cd week03`
2. 패키지 설치: `npm install`
3. 서버 실행: `npm run dev` (또는 `node app.js`)

## 관리자 계정 만드는 법
1. 웹 브라우저에서 `/signup` 경로로 접속하여 회원가입을 진행합니다 (예: 아이디 `mickey`).
2. 터미널(week03 폴더 위치)에서 아래 명령어를 실행하여 해당 유저를 관리자로 승격합니다:
   `node make-admin.js mickey`
3. 로그아웃 후 다시 로그인하면 상단에 `관리자` 링크가 활성화됩니다.

## 구현한 라우트
- `GET /posts`: 게시글 목록 조회 (JOIN을 통해 작성자 이름 포함)
- `GET /posts/new`: 글쓰기 폼 화면 (로그인 필수)
- `POST /posts`: 새 글 저장 (로그인된 유저의 id로 작성자 매핑)
- `GET /posts/:id`: 글 상세 보기 (작성자 이름 및 삭제 권한 검증 UI 포함)
- `POST /posts/:id/delete`: 글 삭제 (작성자 본인 또는 관리자만 가능)
- `GET /admin`: 관리자 전용 회원 목록 페이지 (관리자만 접근 가능)

## 점검 결과
- 데이터베이스(`board.db`)에 회원 및 게시글 정보가 정상적으로 유지됨.
- 비밀번호 해시화(`bcryptjs`) 및 세션 관리(`express-session`) 정상 동작 확인.

## (도전) 구현한 것
- 작성자 본인 및 관리자만 게시글을 삭제할 수 있는 권한 분리 미들웨어 구현
- `make-admin.js` 스크립트를 통한 간편한 관리자 권한 부여 기능
